# 📁 web Portfolio (김서현)
본 프로젝트는 외부 라이브러리 사용을 최소화하고 **Vanilla CSS**와 **JavaScript**를 활용하여 직접 구현한 모바일 반응형 3D 인터랙티브 웹사이트입니다.

## 🛠 Portfolio Tech Stack
- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Effect:** 3D Carousel, Custom Animations, Intersection Observer API

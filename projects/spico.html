내 손안의 AI 발표 코치

학교 발표, 면접 등 다양한 상황에서 말하기는 필수가 되었지만,
혼자 연습하긴 어렵고 민망한 발표.

Spico는 누구나 혼자서도 발표 실력을 키울 수 있도록, 실시간 피드백과 청중 모드와 같은 실전 연습 환경을 제공합니다.

01. MISSION & VISION

준비와 실전 사이의
간극을 메우다

발표가 무서운 이유는 "준비 부족"이 아니라, 준비한 대본과 실제 입 밖으로 나오는 말 사이의 괴리 때문입니다. Spico는 이 찰나의 순간을 기술로 포착합니다.

Problem

녹화 후 확인하는 사후 피드백의 한계

Solution

말하는 즉시 반응하는 실시간 가이드

02. PRACTICE MODES

완벽한 발표를 위한
3가지 연습 모드

01

코칭 모드

대본을 보며 실시간 분석 및 피드백을 제공받는 기초 연습 모드입니다.

02

실전 모드

실제 청중 앞에서 하듯, 예상 질문(Q&A)과 타이머를 포함한 리허설 모드입니다.

03

랜덤 스피치

랜덤한 주제에 대해 순발력 있게 답변하는 훈련을 할 수 있습니다.

03. KEY CONTRIBUTIONS

핵심 프로젝트 기여

01

실시간 STT 결과와 대본 문단 매칭 로직 구현

Android SpeechRecognizer의 Partial Result를 활용한 정밀한 하이라이팅과 실시간 RMS 파형 시각화로 몰입감 있는 발표 연습 환경을 구축했습니다.

Android SpeechRecognizer Levenshtein Distance
02

Jetpack Compose 기반 대본 편집 제스처 로직 구현

롱프레스(이동), 스와이프(삭제) 등 직관적 제스처를 통해 사용자가 흐름을 끊지 않고 빠르고 편안하게 대본을 수정할 수 있는 UX를 구현했습니다.

Jetpack Compose Custom Gestures
03

Clean Architecture 기반 레이어 분리 설계

Presentation, Domain, Data 레이어를 엄격히 분리하여 의존성을 단방향으로 관리하고, 단위 테스트가 용이한 유연한 아키텍처를 설계했습니다.

Clean Architecture
04

Jira 기반 이슈 관리 및 커밋 메시지 자동화

Gitlab Hook 기반의 Jira 상태 자동 전환 및 GPT 커밋 메시지 생성기를 도입하여 개발 외적인 커뮤니케이션 비용을 최소화했습니다.

Gitlab Hooks Jira Automation GPT-4
04. INTERACTIVE COACHING

말하는 순간,
화면이 반응합니다

STT Highlighting

Partial Result 기반 유사도 측정으로 현재 읽고 있는 문단을 자동 추적합니다.

RMS Volume Monitoring

성량과 발화 속도를 실시간 분석하여 시각적 코칭을 제공합니다.

REAL-TIME
Dynamic Waveform

사용자의 목소리 파형을 즉각적으로 시각화하여 생동감을 더합니다.

AI Feedback

연습 종료 후 AI가 발화 내용을 요약하고 예상 질문을 생성합니다.

05. GESTURE ENGINE

손끝에서 완성되는
직관적 편집 경험

단순한 클릭을 넘어, 롱프레스(Long-Press)로 문단을 이동하고 스와이프(Swipe)로 삭제하는 직관적인 편집 흐름을 설계했습니다. 복잡한 메뉴 조작 없이 직관적인 제스처만으로 대본을 수정할 수 있어, 사용자가 흐름을 끊지 않고 보다 빠르고 편안하게 편집할 수 있습니다.

06. ARCHITECTURE

보이지 않는 곳의
정교한 설계

📐

엄격한 레이어 분리

Presentation, Domain, Data 레이어를 엄격히 분리하여, 비즈니스 로직이 외부 요소(UI, DB)에 의존하지 않는 단방향 의존성 규칙을 적용했습니다.

☁️

유지보수성 최적화

기능이 추가될수록 복잡해지는 코드의 유지보수성을 확보하고, UI 로직과 비즈니스 로직의 강한 결합도를 해결하기 위해 도입했습니다.

⚙️

쉬워진 테스트 검증

모듈 간 결합도를 낮춰 변경에 유연하게 대처할 수 있었으며, 특히 UI 없이도 핵심 로직을 독립적으로 검증하는 테스트 용이성을 극대화했습니다.

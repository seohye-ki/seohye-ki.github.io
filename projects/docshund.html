언어 장벽을 넘어 지식을 나누다

IT 공식 문서를 함께 번역하고 공유하는 집단지성 번역 플랫폼입니다. 영어 장벽으로 인한 정보 격차를 해소합니다.

01. MISSION

"공식 문서는 정확해야 하지만,
누구나 쉽게 읽을 수 있어야 합니다."

높은 언어 장벽과 파편화된 번역 정보

영어 울렁증 부정확한 자동 번역

집단지성을 통한 신뢰할 수 있는 집단 번역

문단별 번역 투표 함께 만드는 지식

DocshunD는 혼자 읽기 힘든 방대한 공식 문서를 개발자들이 힘을 합쳐 번역하고, 실시간으로 질문과 답변을 주고받으며 함께 성장하는 공간입니다.

02. CORE FEATURES

함께 만드는 번역

문단별 번역 제안

문서 전체가 아닌 문단 단위로 쪼개어 번역을 제안할 수 있어 부담 없이 참여 가능합니다.

투표 기반 베스트 번역

가장 많은 추천을 받은 번역이 대표 번역으로 노출되어, 집단지성에 의한 품질 관리가 이루어집니다.

04. TECH & ROLE

사용자 경험을 위한 기술

AxiosInterceptor.js 
const instance = axios.create({
    baseURL: process.env.REACT_APP_API_URL,
});

// 요청 인터셉터: JWT 자동 주입
instance.interceptors.request.use((config) => {
    const token = localStorage.getItem('accessToken');
    if (token) config.headers.Authorization = `Bearer ${token}`;
    return config;
});

// 응답 인터셉터: 예외 처리 표준화
instance.interceptors.response.use(
    (response) => response,
    (error) => {
        if (error.response.status === 401) {
            handleLogout(); // 세션 만료 시 자동 처리
        }
        return Promise.reject(error);
    }
);

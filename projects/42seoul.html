C로 배우는 구조와 시스템
2023.08 - 2024.07

자기주도 학습의 정점

교수와 교재 없이 동료들과 스스로 정답을 찾아가며 소프트웨어의 본질을 탐구하는 법을 배웠습니다.

특히 C언어 기반의 밑바닥 구현을 반복하며 서비스의 근간이 되는 컴퓨터 과학의 핵심 원리들을 깊이 있게 익혔습니다.

01. ALGORITHM

Push_Swap

한정된 2개의 스택(Stack A, B)과 제한된 명령어 집합만을 사용하여, 무작위로 섞인 데이터를 최소한의 동작 횟수로 정렬하는 알고리즘 과제입니다.

퀵 정렬(Quick Sort)과 그리디 알고리즘을 응용하여 복잡도(Complexity)를 최적화하는 훈련을 수행했습니다.

02. SYSTEM & CONCURRENCY

Philosophers

운영체제의 고전적인 '식사하는 철학자 문제'를 통해 교착 상태(Deadlock)와 경쟁 상태(Race Condition)를 해결했습니다.

Multi-Thread & Mutex

pthread를 활용하여 스레드 간 자원 공유를 제어하고, Mutex Lock을 통해 데이터 무결성을 보장했습니다.

03. SYSTEM COMMUNICATION

Minitalk

UNIX 시그널(SIGUSR1, SIGUSR2)만을 사용하여 서버와 클라이언트 간의 문자열 통신 프로그램을 구현했습니다.

문자열을 비트(Bit) 단위로 쪼개어 전송하고, 수신 측에서 비트 연산을 통해 다시 문자로 재조립하며 저수준 통신(Low-level Communication)의 원리를 깊이 이해했습니다.

04. COMPUTER GRAPHICS (2D)

So_Long

MiniLibX 라이브러리를 활용한 2D 타일 기반 게임입니다. 맵 파일 파싱(Parsing)부터 렌더링 루프(Render Loop), 키보드 이벤트 처리를 직접 구현하며 게임 엔진의 기초 구조를 학습했습니다.

  • Map 유효성 검사 (Flood Fill 알고리즘)
  • Sprite 렌더링 및 이벤트 훅(Hook) 처리
05. COMPUTER GRAPHICS (3D)

Cub3D

Raycasting(광선 투사) 기술을 이용하여 울펜슈타인 3D 스타일의 1인칭 3D 렌더링 엔진을 밑바닥부터 구현했습니다.

삼각함수를 이용한 거리 계산, 텍스처 매핑(Texture Mapping), 시점 변환 등을 통해 3D 그래픽스의 수학적 원리를 심도 있게 배웠습니다.

06. KEY LEARNINGS

기여의 핵심,
주요 기술적 기여

01

C언어 밑바닥부터 쌓아올린 CS 지식과 구현력

라이브러리 없이 메모리 관리, 자료구조(Stack, Tree), 프로세스/스레드 동기화 등을 직접 구현하며 컴퓨터 과학의 근본적인 원리를 이해하고 견고한 코드를 작성하는 능력을 길렀습니다.

Low-level Programming Memory Management Algorithms
02

동료 평가(Peer Evaluation): 코드 설득과 피드백

작성한 코드를 동료에게 라인 단위로 설명하고 질문에 대답하는 평가 과정을 수없이 거치며, 단순히 동작하는 코드가 아닌 '읽기 쉽고 논리적인 코드'를 작성하는 습관과 커뮤니케이션 능력을 키웠습니다.

Code Review Technical Communication
03

엄격한 코딩 컨벤션(Norme) 준수

함수 길이 25줄 제한, 변수 선언 위치 등 42서울만의 엄격한 코딩 규칙(Norme)을 준수하며, 제약 사항 속에서도 가독성을 해치지 않고 효율적인 로직을 설계하는 논리적인 설계 역량을 기르고, 클린코드의 중요성을 경험했습니다.

Coding Standards Clean Code
07. GROWTH & CULTURE

체계적인 동료 평가 (Peer Review)

42Seoul의 모든 과제는 동료 3명 이상의 평가를 통과해야 합니다. 동료평가를 받으며 내 코드를 논리적으로 방어(Defense)하고, 동료평가를 하며 타인의 코드를 분석하고 다양한 시각을 배웠습니다.

엄격한 코딩 컨벤션 (Norminette)

함수 길이 25줄 제한, 변수 선언 위치 등 엄격한 규칙(Norminette)을 준수하며, 가독성 높고 모듈화된 코드를 작성하는 습관을 뼛속 깊이 새겼습니다.

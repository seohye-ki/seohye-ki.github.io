관심 팀을 설정하고 알림을 통해 경기를 놓치지 않도록 도와줍니다.
AI팀 추천과 챗봇으로 새로운 팬심의 즐거움까지 느낄 수 있습니다.

01. SERVICE LOGIC

"단순한 달력이 아니라,
팀을 향한 애정을 시각화했습니다."

경기 일정 히트맵

FullCalendar를 커스터마이징하여, 일자별 경기 밀도에 따라 색상의 농자가 변하는 직관적인 UI를 구현했습니다.

관심 팀 맞춤 설정

야구, 축구, 농구 등 종목에 관계없이 내가 응원하는 팀만을 골라 나만의 캘린더를 구성할 수 있습니다.

경기 임박 알림 서비스

경기 시작 1시간 전, 놓치지 않도록 이메일 알림을 자동 발송하는 스케줄링 시스템을 구축했습니다.

03. SECURITY & AUTH

"로그인부터 데이터 보호까지,
사용자의 신뢰를 설계했습니다."

SecurityConfig.java 
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) {
    http
        .csrf().disable()
        .sessionManagement()
        .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
        .and()
        .authorizeRequests()
        .antMatchers("/api/auth/**").permitAll()
        .anyRequest().authenticated()
        .and()
        .addFilterBefore(new JwtAuthenticationFilter(jwtTokenProvider), 
                         UsernamePasswordAuthenticationFilter.class);
    
    return http.build();
}
🔐 Spring Security + JWT

Session 대신 JWT(Json Web Token) 기반의 Stateless 인증을 구현하여 확장성 있는 인가(Authorization) 처리를 설계했습니다.

🛡️ BCrypt 암호화

사용자 비밀번호는 BCrypt 해싱 알고리즘을 적용하여 DB 유출 시에도 복호화가 불가능하도록 강력하게 보호했습니다.
